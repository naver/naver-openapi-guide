# 네이버 로그인

네이버 로그인은 사용자가 네이버 아이디로 여러분의 서비스에 간편하게 로그인하게 해 주는 기능입니다. 로그인에 더해 카페·캘린더·네이버페이 배송지 등 다양한 연동을 제공합니다.

## 구성

* [네이버 로그인 API](/products/login/api) — 네이버 로그인 인증과 연동 API 소개
* [카페](/products/login/cafe) — 카페 가입·글쓰기 연동
* [캘린더](/products/login/calendar) — 사용자 캘린더 일정 등록
* [네이버페이 배송지 정보](/products/login/payaddress) — 등록 배송지 조회로 주문 간소화
* [적용 가이드](/products/login/userguide) — 로그인 효과를 높이는 적용 방법
* [적용 사례](/products/login/bestpractice) — 네이버 로그인 도입 서비스 사례
