# 캡차

네이버 서비스에서 사용하고 있는 이미지 캡차 기능을 고객의 서비스에 활용하여 사람과 컴퓨터를 판별해 어뷰징을 막을 수 있습니다. 회원 가입 또는 비밀번호 찾기에서 실제 사용자의 순수한 입력만 받고, 어뷰저를 가려내고 싶을 때 유용합니다.

### 손쉬운 사용

RESTful API 형태로 CAPTCHA를 요청하고, JSON 타입으로 원하는 정보를 얻을 수 있어 고객의 서비스에 쉽고 간편하게 적용할 수 있습니다. CAPTCHA의 질문은 이미지 형태로 제공되므로 고객의 서비스 UI에 최적화하여 사용 가능합니다.

![](./images/cont/img_intro_captcha01.png)네이버 로그인에서 이미지 캡차 사용 예

### 향상된 보안성

주체가 사람인지 컴퓨터인지를 효과적으로 판별하기 위해 스타일이 다른 두 종류의 캡차 이미지를 랜덤으로 제공합니다. 어뷰징이 의심되는 입력 패턴이 확인되면, 별도의 강화된 보안 기준이 적용되므로 안심하고 서비스를 운영할 수 있습니다.
