# 서비스 API

네이버가 제공하는 다양한 서비스 API를 소개합니다. 검색·데이터 분석부터 콘텐츠 공유, 모바일앱 연동까지 서비스에 필요한 기능을 선택해 활용할 수 있습니다.

## 구성

* [데이터랩](/products/service-apis/datalab) — 통합 검색어 트렌드·쇼핑인사이트 분석
* [검색](/products/service-apis/search) — 분야별 네이버 검색 결과 제공
* [캡차](/products/service-apis/captcha) — 이미지 캡차로 자동 입력 방지
* [네이버 공유하기](/products/service-apis/navershare) — 콘텐츠를 네이버 서비스에 공유
* [모바일앱 연동](/products/service-apis/naverapp) — URL Scheme 기반 네이버 앱 연동
* [네이버 오픈메인](/products/service-apis/openmain) — 네이버 메인에 웹페이지 추가
