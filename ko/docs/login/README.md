# 네이버 로그인 개발 가이드

네이버 로그인은 OAuth 2.0 프로토콜 기반의 사용자 인증 기능으로, 서드파티 애플리케이션이 네이버 사용자의 동의를 받아 로그인과 회원 정보 연동을 구현할 수 있게 합니다. 이 가이드는 적용에 필요한 개념부터 API 명세, 플랫폼별 연동 방법까지 단계적으로 다룹니다.

## 구성

* [개요](/docs/login/overview) — 네이버 로그인 소개와 주요 특징, 적용 절차
* [검수 가이드](/docs/login/verify) — 서비스 적용 전 사전 검수 절차
* [개발 가이드](/docs/login/devguide) — 로그인 연동 개발 흐름과 로그인 버튼 사용 규정
* [API 명세](/docs/login/api) — 인증·토큰 발급 API와 회원 프로필·카페·캘린더·네이버페이 배송지 API
* [튜토리얼](/docs/login/android) — Android·iOS·Web·Windows 등 플랫폼별 연동 예제
* [SDK 다운로드](/docs/login/sdks) — 플랫폼별 라이브러리와 버전 이력
