# API 공통 가이드

네이버 오픈API는 네이버 플랫폼의 기능을 외부 개발자가 쉽게 이용할 수 있게 웹 또는 SDK 형태로 공개한 기술들입니다.

## API 공통 가이드 개요

API 공통 가이드는 네이버 오픈API를 사용해 클라이언트 애플리케이션을 개발할 때 미리 알아 두어야 하는 내용을 설명합니다.

> - 최종 수정일: 2021년 8월 27일</li>
>
> 이 문서의 내용은 언제든지 변경될 수 있습니다.
